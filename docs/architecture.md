# RythuBandhu - System Architecture

## Overview
RythuBandhu is an agricultural incident-response platform designed to streamline problem reporting by farmers and case management by Agricultural Extension Officers (AEOs).

## Tech Stack
- **Frontend**: React + Vite (Vanilla CSS, clean white UI design system)
- **Backend**: Python + FastAPI
- **Database**: Supabase PostgreSQL with PostGIS extension
- **Version Control**: Git + GitHub

## Phase 1 Scope
- Core repository and folder hierarchy.
- FastAPI backend with health check endpoint (`GET /health`).
- Clean, minimal, professional white UI frontend scaffold with routes for `/farmer` and `/aeo`.
- Frontend API service module.
- Environment configuration and Supabase integration readiness.
